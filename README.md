# Bug-squasher-browser-game

Bug Squasher is a browser clicker game. Bugs have taken a production server offline. You click a bug in the play arena to squash it, earn points, and spend those points on upgrades: a stronger click, an auto-squash timer, and bug spray that boosts both manual and auto clicks. The game runs in the browser with no install. Refreshing the page starts a new run.

This is Project 01 for CMPA 4303: a working prototype, not the final build.

## Purpose

I built this to learn JavaScript the same way I already think about games (state, a loop, a shop) while staying on plain HTML and CSS. It is for casual players and anyone who has had to squash bugs on a real project. Players should be able to open it on a phone, tap for a minute, and understand it without a long tutorial.

## Tools and Technologies

- **HTML, CSS, and JavaScript** - No framework. I wanted core JS, HTML, and CSS.
- **Visual Studio Code** - Editor I already use, with Live Server for local preview.
- **Git and GitHub Desktop** - Version control.
- **GitHub Pages** - Static hosting on this repo, no build step.
- **Chrome DevTools** - Console and layout checks.
- **LLM assistants** - Idea checks and JS patterns (template literals, `setInterval` / `clearInterval`). Game code is handwritten. Not utilizing agents.
