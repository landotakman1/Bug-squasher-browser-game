About This Project

Bug Squasher is a broswer-based clicker game built with HTML, CSS, and JavaScript for CMPA 4303.

This game was made for casual players and anyone who has spent any time "squashing bugs".

Current build is in scaffolding stage and contains only base components and formatting. More features and improvements will be added in future updates.
