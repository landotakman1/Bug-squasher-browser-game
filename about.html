About This Project

Bug Squasher is a browser-based clicker game built with HTML, CSS, and JavaScript for CMPA 4303.

It is for casual players and anyone who has spent time "squashing bugs" on a real project.

This Project 02 build is a playable prototype: click the bug, earn points, buy Stronger Click, Auto Squash, and Bug Spray. Refreshing the page starts a new run. More motion and polish are planned for Project 02.
